# Система 2026–2027

## Принцип

**Нужен результат, а не максимальное количество занятых часов.**

Школа сама по себе не является отдельным пунктом чек-листа. В список попадают только конкретные действия, которые улучшают нужный результат.

## Недельный минимум

| Направление | Базовое правило |
|---|---|
| ОГЭ | 4 содержательных занятия в неделю, по необходимости усиливать слабые предметы |
| CS50 | регулярная работа до завершения курса |
| Английский | 40 минут ежедневно |
| Спорт | через день |
| Чтение | 10 страниц ежедневно |
| Проекты | 1–2 содержательных блока в неделю, если есть реальная задача |
| ByMeVPN | только поддержка и реальные изменения |

## Правила работы

1. Перед блоком сформулировать **один конкретный результат**.
2. Не считать часы ради часов.
3. Закончил задачу с нужным результатом — закрыл её.
4. Не держать одновременно десять «главных» задач.
5. Если обязательный минимум закрыт, свободное время действительно свободно.
6. Сон и спорт не компенсируются дополнительной работой.
7. Новая идея не меняет план, пока не прошла фильтр в [[03 Проекты/Идеи/Идеи проектов]].

## Недельный обзор — 10 минут

Раз в неделю проверить:

- что из главного реально продвинулось;
- где образовался долг;
- что можно удалить из плана;
- какая одна задача имеет наибольший эффект на следующей неделе.

## Аварийный режим

Если времени или сил мало, оставить только:

**ОГЭ + CS50 + английский + сон/спорт.**

Проекты и прочее временно сжимаются, а не создают новый долг.
