# Безопасность

В этой версии хранилища **нет рабочих паролей, токенов, приватных ключей и recovery-кодов**.

Храни секреты в менеджере паролей или секрет-хранилище. В репозиторий не коммить:

- `.env`;
- API keys / bearer tokens;
- private keys / certificates с приватным ключом;
- recovery codes;
- пароли от панелей и аккаунтов.

Если секрет однажды попал в Git/Telegram/общий файл, считай его скомпрометированным и ротируй.
