# 🛒 ByMeShop — production-спецификация (v1, монолит)

> Промпт-спецификация для генерации production-кода Telegram-бота. Первая, более компактная версия (до перехода на PostgreSQL/Docker в [[ByMeShop — спецификация v2 (PostgreSQL+Docker)]]).

## Стек технологий

- **Библиотека:** aiogram 3.x (последняя стабильная версия)
- **База данных:** SQLite через асинхронный `aiosqlite`. Автоинициализация таблиц `users`, `orders`, `items` при старте

## 🎨 Дизайн и UI/UX

- Чеки и системные экраны разделять линиями: `──────────────────────`
- Тематические эмодзи в начале строк
- Все важные данные (UID, логины, ID заказов, суммы, почты) — в тег `<code>` для копирования в один клик
- Навигация через `message.edit_text` на инлайн-кнопках (без спама сообщениями)
- Везде кнопки `[🔙 Назад в меню]` или `[❌ Отмена]`

## ⚙️ Ветки логики (FSM States)

### 🎮 Игры → 🎯 Standoff 2
- **Голда:** запрос количества (валидация: число > 0), расчёт 1 шт = 0.5 руб, запрос названия скина и скриншота, финальный чек
- **Аккаунты:** динамическая галерея товаров из БД `items` (`[⬅️ Назад]` / `[Вперед ➡️]` / `[🛒 Купить]`), при покупке — бронь на 15 минут и генерация инвойса, после оплаты — автовыдача строки «логин:пароль» из БД

### 🎮 Игры → 👑 Brawl Stars
- **Гемы:** тарифы [30/70], [80/180], [110/310], [170/370], [200/500], [250/700], [360/760], [440/1140], [530/1230], [720/1620], [950/1950], [2000/4000] (формат гемы/рубли). После выбора — почта (Supercell ID) с валидацией, затем 6-значный код. Финальный чек
- **Бравл Пасс / Пропасс:** [Обычный / 555 руб] или [Plus / 888 руб]. Почта и код. Финальный чек

### 🎮 Игры → ☄️ PUBG Mobile (UC)
- Тарифы: [60/60], [325/300], [660/500], [1800/1500], [3850/3000] (UC/рубли). UID игрока (валидация: только цифры, 8–12 символов). Финальный чек

### 🎮 Игры → 💎 Free Fire & 🧱 Roblox
- Заглушка: «⚠️ Данный раздел находится в разработке техническим отделом ByMeShop. Приносим извинения!» + кнопка `[🔙 Назад в меню]`

### 📱 Телеграм
- **Аккаунты:** выбор [Купить каналы] или [Купить сессии (.session)], ввод количества, проверка наличия в БД, чек-оплата, после оплаты — выдача ссылки/текста
- **Звёзды (1★ = 1 руб):** [👤 Для себя] (автоматически берёт chat_id) или [🎁 В подарок другу] (ввод `@username` с валидацией символа `@`). Расчёт цены 1 к 1. Финальный чек

### 🔌 Сервисы → 🚂 Steam (пополнение)
- Запрос ЛОГИНА (не никнейма!) с предупреждением жирным текстом о потере денег при ошибке, валидация логина
- Сумма от 100 до 10000 руб. Финальный чек

## 💳 Касса и авто-проверка оплаты

Класс для работы с платёжным API (CryptoPay API или AAIO / ЮKassa):

1. Заказ сохраняется в SQLite со статусом `PENDING`
2. Генерация ссылки на оплату, кнопки `[🔗 Ссылка на оплату]` и `[🔄 Проверить оплату]`
3. Хендлер «Проверить оплату» делает запрос к API платёжки. При успехе: статус → `PAID`, клиенту — «🎉 Оплата прошла успешно!», админу — полные данные клиента (UID, логин, тариф, скриншот) для выдачи

## 👑 Админ-панель (`/admin`)

Доступна только для `ADMIN_ID`:
- Статистика: пользователи, заказы, выручка
- Добавление аккаунтов Standoff 2 в БД
- Рассылка текстового сообщения всем пользователям

> Токены и константы (`BOT_TOKEN`, `ADMIN_ID`, `API_KEYS`) выносятся в начало кода — см. [[Секреты — требуют внимания]] для реальных значений, найденных в исходных заметках.
