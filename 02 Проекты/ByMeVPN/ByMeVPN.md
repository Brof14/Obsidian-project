# 🔒 ByMeVPN

> Отдельного описательного файла про проект в архиве не было — собрано из упоминаний в [[Python]], [[Go]], [[Летний план 2026]] и [[Итальянский ИТ-трек]].

## Известный контекст

- VPN-сервис на технологиях Xray / Sing-Box (Go-инфраструктура)
- Бэкенд автоматизируется на Python: Docker API, SSH-скрипты, генерация ключей VLESS
- Рассматривается как источник пассивного дохода для покрытия аренды в Европе (~€500/мес) — см. [[Итальянский ИТ-трек]]
- В планах — вывести на чистый пассивный доход через оптимизацию серверных издержек (более дешёвые, но стабильные VPS-локации) и масштабирование подписочной модели

## Материалы проекта

1. [[ByMeVPN — маркетинг и рефералка]] — рекламные тексты, условия рефералки, гайд по генерации рекламных видео
2. [[ByMeVPN — доработка бота (спецификация 3x-ui)]] — техспека по интеграции с панелью 3x-UI
3. [[ByMeVPN — сайт личного кабинета (спецификация)]] — Node.js сайт, синхронизированный с ботом через общую БД
4. [[ByMeVPN — инструкция подключения и ссылки]] — инструкция для пользователей (Android/iOS), рабочие ссылки
