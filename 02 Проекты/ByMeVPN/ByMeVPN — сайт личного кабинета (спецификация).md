# 🖥 ByMeVPN — сайт личного кабинета (спецификация, Node.js)

Промпт-спецификация для сайта, синхронизированного с ботом через общую БД. Взято из Telegram «избранное» (10.04.2026).

**Контекст:** Senior Fullstack Developer. Перевести проект на Node.js и интегрировать с существующей БД (PostgreSQL) в отдельном Docker-контейнере на VDS. База общая для сайта и Telegram-бота.

## 1. Интеграция с внешней БД (Docker)

- Подключение к PostgreSQL через Prisma или Sequelize.
- Параметры подключения — из `.env` (хост, порт, логин, пароль).
- Архитектура таблиц должна поддерживать синхронизацию: купил ключ в боте → он сразу появляется в личном кабинете на сайте. Таблицы: `Users`, `Keys`, `Transactions`.

## 2. Авторизация (SSO Style)

- JWT или долгоживущие сессии (`express-session` + `connect-pg-simple`).
- После регистрации/оплаты — автоматическая авторизация.
- «Запомнить меня»: 30 дней без повторного ввода данных.

## 3. Логика выдачи и синхронизации ключей

- API-роут для приёма платежей (Webhook).
- После оплаты: найти пользователя по ID (из бота или сайта) → присвоить свободный ключ из `Keys` → уведомить (бот/почта).
- Пользователь на сайте видит список своих ключей в реальном времени.

## 4. Дизайн (Tailwind CSS)

Стиль: «Dark Cyber-Tech». Личный кабинет: статус подписки, купленные ключи (кнопка «Скопировать»), кнопка быстрого продления. Glassmorphism, анимированные градиенты, индикаторы нагрузки серверов.

## 5. Техническая часть

- `docker-compose.yml` только для приложения — БД во внешнем контейнере (`extra_hosts` или внешняя сеть).
- Валидация данных — Zod, логирование — Winston (виден каждый шаг оплаты).
- Порядок работы: сначала проанализировать структуру папок → предложить схему БД, связывающую сайт и бота → после одобрения приступать к коду.
