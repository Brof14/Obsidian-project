# 🎮 Pin&Pan

2D co-op puzzle-platformer на Godot (с прицелом на UE5/6 для сиквела). Упоминается рядом с портфолио для поступления в [[Saxion University]] (геймдев-направление).

## ⚡ С чего начать

1. [[Приоритет разработки (что делать сейчас)]] — что делать прямо сейчас: только Главное меню → Пролог → Акт I, не трогать Акт II–III
2. [[PinPan_Story_Gameplay_v2]] — сводный документ v2: обоснование механик, ответ на «похоже на Unravel»

## 📖 Сценарий и дизайн (актуальная версия, v2)

1. [[01_Intro_Cinematic]] — вступительный ролик до главного меню (35 сек, без текста)
2. [[02_Main_Menu]] — главное меню, полная проработка (UI, курсор, звук, анимации)
3. [[03_Prologue]] — интерактивный пролог (4–6 минут)
4. [[04_Act_1_Full]] — Акт 1: Льняные поля + Шерстяной лес
5. [[05_Act_2_Full]] — Акт 2: Шёлковые пики + Зал Эха
6. [[06_Act_3_Full]] — Акт 3: Истрёпанные пустоши + Сердце Станка

## 🎬 Прочие материалы проекта

- [[Pin&Pan — трейлер (промпт для нейросети)]] — готовый промпт для Runway/Pika/Sora (маркетинговый ролик, не путать с [[01_Intro_Cinematic]] — это ролик для трейлера/соцсетей, а не внутриигровая катсцена)
- [[Pin&Pan — Symbiont (альтернативная концепция)]] — альтернативная, более тёмная версия сюжета и геймплея (статус решения не зафиксирован, не входит в канон v2)
- [[Промт — доработка документации v2 (для ИИ)]] — исходный промпт, которым была сгенерирована текущая версия v2 (для истории/повторного использования)

## 🗄 Архив

Более ранняя, короткая версия дизайн-документа (сюжет, геймплейные системы, UI одним пасом) — заменена версией v2 выше, оставлена в [[Архив (устарело, до v2)]] как история.
