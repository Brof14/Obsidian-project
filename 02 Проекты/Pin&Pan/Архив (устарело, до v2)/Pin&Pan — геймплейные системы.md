# 🎮 Pin&Pan — геймплейные системы (2D co-op puzzle-platformer)

## Core Loop

1. Вход в зону
2. Понимание механики
3. Фейл (хаос)
4. Осознание
5. Комбинация
6. Успех

## Основные системы

**1. Нить (ядро)**
- длина
- натяжение
- перегрев
- состояния: elastic / bind / edge / pulse

**2. Риск**
- падение → утягивание
- перегрев → рандомные эффекты
- спасение → дебафф

**3. Прогрессия**
- новые состояния нити
- сложность комбинаций
- синхронность

## Механики (из монтажа возможностей)

1. Натяжение нити открывает дверь
2. Slingshot-запуск через шипы
3. Обмотка врага → обездвиживание
4. Разрезание препятствия нитью (яркая искра)
5. Игроки тянут вместе → синхронное позиционирование
6. Синхронный прыжок → дополнительная высота
7. Обмен позициями (визуальный твист-эффект)

Слова-оверлеи на каждый клип: Pull / Launch / Trap / Cut / Sync / Swap.

## Миры (структура)

- **Мир 1 — Осознание:** базовые механики, обучение через фейлы
- **Мир 2 — Контроль:** враги, обмотка / разрезание
- **Мир 3 — Пространство:** якоря, вертикальность
- **Мир 4 — Время:** эхо, синхронизация
- **Мир 5 — Перегрузка:** перегрев, сложные комбинации
- **Мир 6 — Выбор:** минимализм, финал

## План производства

От 2D-прототипа на **Godot** к возможному AAA-графону на **UE5/6** (для сиквела/второй части). Технические спецификации трейлера — 1920×1080, 16:9, 60 FPS, динамическая камера, неоновый свет.

## Следующий логичный шаг (по состоянию на 08.2026)

Не расписывать сразу все 6 миров до мелочей. Сделать **Greybox** (уровень из простых кубиков) в Godot, где работает только одна механика — «Нить и натяжение». Проверить, весело ли просто прыгать и тянуть друг друга — если весело даже с кубиками, значит механика рабочая.

Текущий статус на тот момент:
1. Глубокий лор (Ткач, Нити, Пустота) — готов, см. [[Pin&Pan — сюжет и лор]]
2. Инновационная механика (физика нити + кооп/синхронизация) — придумана
3. План производства (от 2D на Godot к AAA-графону на UE) — намечен
4. Визуальные промпты для тизеров через нейросети — готовы, см. [[Pin&Pan — трейлер (промпт для нейросети)]]

Идея на подумать: записать на аккордеоне короткую «тему Ткача» под промпты для интро — для нужного вайба.
