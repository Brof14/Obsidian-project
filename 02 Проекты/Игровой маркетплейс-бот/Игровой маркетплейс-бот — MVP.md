# 🎮 Игровой маркетплейс-бот — упрощённый MVP

> Более простая, ранняя версия промпта для Telegram-бота продажи игровой валюты — без БД и платёжной интеграции, чисто UX-каркас. По смыслу пересекается с [[ByMeShop — обзор проекта]], но это отдельная, более минималистичная итерация.

## Технические требования

- **Библиотека:** aiogram 3.x
- **Архитектура:** разделение на хэндлеры через Router. Чистый, готовый к запуску код
- **Интерфейс:** только Inline-кнопки (`InlineKeyboardMarkup`). В каждом подменю — кнопка «Назад»

## Логика меню и кнопок

### 1. Главное меню (`/start`)
Текст: «Привет! Добро пожаловать в игровой маркетплейс. Выбери игру:»
Сетка 2×2: `[ Brawl Stars ] [ Standoff 2 ]` / `[ PUBG ] [ Free Fire ]`

### 2. PUBG и Free Fire
Заглушка: «⚠️ Этот раздел сейчас находится в разработке. Вернись позже!» + кнопка «Назад».

### 3. Standoff 2
Текст: «⚔️ Раздел Standoff 2. Здесь ты можешь выгодно купить или продать голду по ID.»
- Кнопки «Купить голду» / «Продать голду» + «Назад»
- **Купить голду** → пакеты (по строке каждый): 100 голды — 60 руб, 300 — 165 руб, 500 — 260 руб, 1000 — 490 руб, 3000 — 1400 руб + [Назад]
- **Продать голду** → текстовая заглушка: «Укажи количество голды для продажи. Наш курс скупки: 1G = 0.3 руб. (Минимум 100G). Напиши количество в чат:»

### 4. Brawl Stars
Текст: «⭐ Раздел Brawl Stars. Выбери пакет гемов для покупки:»
Пакеты (каждый на новой строке) + «Назад»: 30 Гемов — 100 руб, 80 — 250 руб, 170 — 500 руб, 360 — 1000 руб, 950 — 2500 руб.

### 5. Обработка кликов по пакетам
Сообщение: «Вы выбрали пакет [Название пакета]. Переход к оплате... (Интеграция платёжной системы будет добавлена позже)».

## Примечание

Токен бота заменяется константой `BOT_TOKEN` в начале кода — см. [[Секреты — требуют внимания]] для реальных значений из исходных заметок.
