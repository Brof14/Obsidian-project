# Архив

Здесь лежит то, что может понадобиться как история или справка, но не должно мешать текущей работе.

## Что сюда попадает

- старые версии спецификаций;
- завершённые/замороженные проекты;
- прошлые планы и расписания;
- старые учебные материалы;
- страновые исследования, которые сейчас не используются.

## Что сюда не попадает

Пароли, токены, приватные ключи, recovery-коды и другие секреты. Они **удалены из этой версии хранилища**.

Архив не нужно регулярно «обслуживать». Его задача — быть тихим.
