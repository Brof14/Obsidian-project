# 🧰 Инструменты и находки (из Telegram «избранное»)

Отобрано из ~400 репостов каналов «Эксплойт», «NN» и других (02.2025–08.2026) — только то, что имеет смысл держать под рукой как справочник инструментов. Новости, мемы, кликбейт и разовые акции — не включены (их актуальность/доступность к моменту чтения не гарантирована).

## Каталоги нейросетей и «всё в одном»

- **Hugging Face Spaces** — каталог из сотен тысяч нейросетей, бесплатно, без регистрации: https://huggingface.co/spaces
- **GlobalGPT** — GPT, Claude, DeepSeek, Midjourney, Perplexity в одном сервисе: https://glbgpt.com/
- **alphaXiv** — научные статьи + Claude для рефератов/курсовых: https://www.alphaxiv.org/explore

## Конкретные нейросети-инструменты

- **Whisper (WebGPU)** — бесплатная транскрибация аудио/видео в текст: https://huggingface.co/spaces/Xenova/whisper-webgpu
- **Explain Me Like I'm Five** — объясняет сложные темы простым языком: https://explainlikeimfive.io/
- **Elphame** — генератор обучающих курсов из 10 модулей по любой теме: https://elphame.com/

## Шпаргалки и справочники для разработки

- **OverAPI** — шпаргалки почти по всем языкам и технологиям: https://overapi.com/javascript
- **QuickRef** — промты, шорткаты Bash/Python/JS/Photoshop/Figma в одном месте: https://quickref.me/index.html
- **Yeahub** — база вопросов для IT-собеседований (Frontend, Backend, DevOps, QA и др.): https://yeahub.ru/questions
- **Algorithm Visualizer** — интерактивная визуализация алгоритмов на JS/Java/C++: https://algorithm-visualizer.org/

## Статьи по вебдеву

- ТОП-15 UI-библиотек для React: https://proglib.io/p/top-15-ui-bibliotek-dlya-react-v-2025-godu-2025-02-24

## Claude / агенты — инструменты и скиллы

- **Гайд по промтингу Claude** (официальный, от Anthropic): https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices
- Библиотека скиллов для Claude Code (рефакторинг, дизайн, документация): https://github.com/mattpocock/skills
- Библиотека навыков для Claude/Cursor (разработка, дизайн, мета-промты): https://github.com/softaworks/agent-toolkit
- **OfficeCLI** — агент создаёт docx/xlsx/pptx без установленного Office: https://github.com/iOfficeAI/OfficeCLI
- **Diagram Design** — скилл для Claude, делает инфографику/диаграммы (HTML на выходе): https://github.com/cathrynlavery/diagram-design
- **book-to-skill** — превращает книгу/документ (PDF, EPUB, DOCX) в skill для агента: https://github.com/virgiliojr94/book-to-skill
- **Memora** — долгосрочная память между сессиями для Codex/Claude Code (SQLite/S3, семантический поиск): https://github.com/agentic-box/memora
- **Obsidian Mind** — контекстное хранилище/память для Claude Code, Codex, Gemini: https://github.com/breferrari/obsidian-mind
- Список бесплатных API для моделей (Google AI Studio, OpenRouter, GitHub Models и др.): https://github.com/cheahjs/free-llm-api-resources
- **ClankerRank** — сборник задач по программированию на решение через промты (LeetCode для ИИ): https://clankerrank.xyz/
- **ShipOrDie** — жёсткий аудит лендинга/стартапа по URL: https://shipordie.club/roast/startup

## На заметку по геймдеву (в контексте [[Pin&Pan]])

*Clair Obscur: Expedition 33* сделана почти без кода — через визуальный конструктор Blueprints в Unreal Engine (бесплатно), при этом стала главным хитом 2025 года и забрала награды The Game Awards. Хороший аргумент за план перехода Pin&Pan с Godot на UE5/6 без необходимости сразу глубоко знать C++.
