Для того чтобы перенаправить весь трафик нейросетей (Gemini, NotebookLM и их API) через отдельный исходящий IP-адрес на VPS с панелью **3X-UI**, потребуется настроить два элемента: **Outbound** (исходящий шлюз) и **Routing** (правило маршрутизации).

Вот пошаговая инструкция, которую можно передать другому разработчику.

### Шаг 1. Подготовка второго IP на VPS

Убедитесь, что второй IP-адрес привязан к сетевому интерфейсу операционной системы:

1. Проверьте наличие IP в консоли: `ip addr show`.
    
2. Проверьте, пропускает ли Google запросы с этого IP:
    
    Bash
    
    ```
    curl --interface <ВТОРОЙ_IP> -I https://gemini.google.com
    ```
    
    _(В ответе должна быть строка `HTTP/2 200` или `HTTP/2 302`)_.
    

### Шаг 2. Добавление исходящего шлюза (Outbound)

1. Откройте панель **3X-UI**.
    
2. В левом меню перейдите в **Конфигурации Xray** $\rightarrow$ **Расширенный...** (или нажмите **«Исходящие»** на боковой панели).
    
3. В JSON-конфигурации найдите массив `"outbounds"` и добавьте в него новый блок (не забудьте поставить запятую перед добавляемым элементом):
    

JSON

```
{
  "tag": "gemini-out",
  "protocol": "freedom",
  "sendThrough": "<ВТОРОЙ_IP>",
  "settings": {}
}
```

> **Параметр `sendThrough`** указывает Xray принудительно отправлять весь трафик данного шлюза через указанный IP-адрес.

### Шаг 3. Настройка правила маршрутизации (Routing)

1. В левом меню панели перейдите в раздел **«Маршрутизация»** (вкладка _«Маршрутизация»_).
    
2. Нажмите кнопку **`+ Маршрутизация`** (Добавить правило).
    
3. Заполните следующие поля:
    
    - **Тег исходящего (Outbound Tag):** Выберите `gemini-out` (или впишите вручную).
        
    - **Домен (Domains):** Укажите домены Google AI через запятую:
        
        Plaintext
        
        ```
        domain:gemini.google.com, domain:notebooklm.google.com, domain:alkalimakersuite-pa.googleapis.com, domain:generativelanguage.googleapis.com
        ```
        
4. Нажмите **«Создать»**.
    

### Шаг 4. Применение настроек

1. Нажмите синюю кнопку **«Сохранить»** в левом верхнем углу панели 3X-UI.
    
2. Нажмите **«Перезапустить панель»** (или перезапустите Xray через интерфейс).
    

### Как это работает:

- Весь стандартный пользовательский трафик проходит через основной IP VPS.
    
- При обнаружении обращения к доменам `*.google.com` и `*.googleapis.com` из списка, Xray перехватывает его и отправляет во внешний мир через интерфейс `<ВТОРОЙ_IP>`.
