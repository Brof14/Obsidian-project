# 🐳 Полезные команды Docker и Linux

## 💾 1. Контроль и очистка диска

- `df -h /` — свободное место на корневом диске (ГБ/МБ)
- `du -sh /* 2>/dev/null | sort -h` — какая папка в корне съедает больше всего места
- `du -sh /var/log` — размер конкретной папки (например, логов)
- `apt-get autoremove --purge -y && apt-get clean` — удалить старые ядра, неиспользуемые пакеты, очистить кэш `.deb`

## 🧠 2. Оперативная память и процессы

- `free -m` — состояние RAM и Swap (в МБ)
- `ps aux --sort=-%mem | head -n 10` — топ-10 процессов по нагрузке на RAM
- `htop` — интерактивный диспетчер задач (`apt install htop`, если не установлен)
- `kill -9 <PID>` — принудительно завершить процесс по PID
- `killall -9 python` — завершить **все** процессы Python (полезно, если боты размножились)

## 🌐 3. Сеть и порты

- `ss -tulpn` — все программы, слушающие порты (сетевые службы, VPN, веб-серверы)
- `curl ifconfig.me` — узнать внешний IP сервера

## 📑 4. Управление логами (systemd/journald)

- `journalctl --vacuum-time=2d` — очистить системный журнал, удалив логи старше 2 дней (освобождает 1–3 ГБ)
- `journalctl -u caddy -n 50 --no-pager` — последние 50 строк логов сервиса (замените `caddy` на `xray`, `docker` или имя своего бота)
- `journalctl -f -u xray` — логи сервиса `xray` в реальном времени (`Ctrl+C` для выхода)

## 🐋 5. Быстрая зачистка Docker

- `docker ps -a` — все контейнеры (запущенные и остановленные)
- `docker image ls` — список всех скачанных образов
- `docker system prune -a --volumes -f` — «ядерная» команда: удаляет весь скрытый мусор Docker (остановленные контейнеры, неиспользуемые образы, кэш сборки), не трогая то, что работает прямо сейчас
